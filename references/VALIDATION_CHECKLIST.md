# 审计与完整性校验

记录已查与未查范围，不将抽查称为全量校验。只读模式使用已有证据；需要重跑验证时，确保不改变工作区或外部状态，否则仅在获准的隔离环境执行。

## AUDIT

- 统计字节、行数及章节大小；忽略代码围栏中的伪标题，覆盖标题前文本。报告摘要与最大章节，不回显全文。
- Token 使用已可用的本地 tokenizer，注明编码；否则说明估算方法、区间与误差，不将字节数当精确 token 数，不为估算上传私有文档。
- 检查语义重复、历史与当前混杂、过期状态、决定冲突、确认出处缺失；先区分时期和环境。
- 核对未完成任务、阻塞及缺乏验收证据的完成声明。
- 检查相关文档的敏感信息风险，不读取无关凭据文件；未发现不等于保证无泄露。
- 提出迁移落点、恢复方式、保护条目与预期收益。

发现项包含位置、证据、影响及建议，区分事实、推测与未核实事项。

## VALIDATE 与写后检查

| 检查 | 通过依据 |
| --- | --- |
| 人工要求 | 关键要求及阈值、否定条件、环境均保留；实质变更有授权与替代链 |
| 任务 | 原未完成任务逐项有归属，阻塞和待核实项可达，完成有验收证据 |
| 状态与证据 | 源码定位、分支/提交/工作区、版本及环境支持描述；开发、测试和部署分开记录，证据带核验时间与范围 |
| 决定 | 废弃有依据，冲突有双方来源，建议未升格为要求 |
| 引用 | 路径与标题/ID 存在，按文档位置解析；索引回链可接受，互指却无事实落点须报告 |
| 追溯 | 原件可读回，映射覆盖全部原始区段和关键条目；历史不只剩压缩摘要 |
| 入口 | 可找到目标、限制、任务、下一步、验收及相关历史证据，无需先读全部历史 |
| 范围 | 只改授权文档，无删除或越权动作，相同事实重复 UPDATE 无变化 |
| 敏感信息 | 新文档、映射、报告与普通归档无秘密扩散；受影响迁移有受保护恢复点 |

结果标为“通过 / 发现问题 / 未核实”，注明未运行检查及原因。关键条目丢失、无法恢复或秘密扩散时，保留原件、停止相关覆盖，不宣称迁移成功。

## 技能维护时的行为验收

按改动选择隔离场景，使用虚构资料，记录执行前后文件清单、哈希及实际产物：

- **A 迁移**：多版本大文档含重复段落、经验、约束和待办；核对原件恢复、全量映射、信息可达及入口缩小。
- **B 决定**：人工要求与建议/实现冲突；检查原义与差异保留，未擅自替代。
- **C 状态**：新文档声称上线，证据仅支持测试环境；检查环境区分及未核实标记。
- **D 幂等**：相同输入连续 UPDATE 两次；第二次前后文件清单和哈希一致。
- **E 追溯**：从新入口定位历史决定、规则、发布依据与映射，验证链接和恢复哈希。
- **F 边界**：AUDIT / VALIDATE 前后文件不变；写入仅涉及授权文档。用虚假敏感值验证无保护恢复方案时停止复制/覆盖，报告不扩散其值。

格式检查不能证明这些行为通过。保留实跑证据及未测项；[历史验收记录](TEST_RESULTS.md) 仅供维护参考，不是当前项目事实。
