# 审计与完整性校验

AUDIT 和 VALIDATE 不修改项目文件；结果默认在回答中返回。大项目记录本次已查/未查范围，不能把抽查称为全量校验。核验需要执行测试时确认其不会写工作区、访问生产或改变外部状态；否则使用既有证据并说明未重跑，或在获准的隔离环境运行。

## AUDIT：体积、结构与风险

- 统计交接及相关文档字节、行数、章节范围与大小；标题解析忽略代码围栏内的伪标题，包含标题前文本。先展示摘要与最大章节，避免把大文档再输出一遍。
- Token 优先用已可用、明确模型/编码的本地 tokenizer；不可用时给出估算方法和区间，如中文字符约 1–2 tokens/字、其余文本约 3–4 字符/token 的粗估，混合代码有更大误差。不要把字节/4 当成中文的精确值，不为估算上传私有文档。
- 查语义重复、历史与当前混杂、过期状态、相互冲突的决策、缺乏出处的“人工确认”；不同时间/环境的差异先区分再下结论。
- 对照全部未完成任务、阻塞项和“已完成但仍待办”的候选，分别列证据与待核实项。
- 仅检查相关文档是否包含疑似密钥、口令或个人敏感信息；工具输出须脱敏，不输出秘密值，不读取无关 .env 或私钥。未发现不代表保证无泄露。
- 建议迁移落点、恢复方式、保护条目与预期收益；不因建议而直接写入。

报告条目格式：严重度、位置、现象、来源/证据、可信度、影响、建议/解决路径。标注结论是事实、推测还是建议。

## VALIDATE 与写入后的检查

| 检查 | 通过依据 |
| --- | --- |
| 人工要求 | 原有关键要求逐项可找到，含阈值/否定条件/环境；改变有明确授权和替代记录 |
| 未完成任务 | 原任务集合逐项有归属；阻塞和待核实项仍可达；完成有验收证据 |
| 实现与架构 | 源码定位及适用提交/工作区状态支持描述；不可访问明确标为未核实 |
| 版本和环境 | 分支、提交、标签和工作区均在核验范围内；声明版本与部署版本分列 |
| 测试与部署 | 开发、测试、灰度、发布不混淆；测试命令/结果/环境/时间可定位；部署有对应环境证据 |
| 决策 | 已废弃决定有替代依据；未决冲突保留双方来源，不把 AI 建议升格为要求 |
| 引用 | 本地路径和标题/ID实际存在，按所在文档解析；外部访问失败记未核实 |
| 循环与矛盾 | 检查循环引用：正常索引回链可接受，只有互指而没有事实落点的循环应报告；跨文档口径一致 |
| 追溯 | 原始版本可读回；迁移覆盖每个原始区段和关键条目；历史不是多次压缩摘要的唯一副本 |
| 入口可用 | 从 HANDOFF 可找到目标、限制、下一步、验收、任务/决定/经验/发布证据；不需先读全部历史 |
| 范围与幂等 | 只改授权文档、无删除及越权动作；相同状态再次 UPDATE 无重复/无意义时间戳变更 |
| 敏感信息 | 新文档、映射、报告及普通归档均无秘密复制；受影响迁移有可用保护方案才继续 |

结果分为“通过 / 发现问题 / 未核实”，不要把证据不足判成通过。报告未运行的检查及原因。若存在关键要求或任务丢失、无法恢复或秘密扩散，不宣称迁移成功；保留原件，暂停相关覆盖，不自动修改人工决定。

## 技能验收：隔离测试 A–F

更新技能时可用可控资料执行以下场景；不要在真实项目构造假事实。测试资料、结果和诊断文件置于隔离临时目录，既有业务目录只读。执行前保存测试文件清单及哈希；后续按阶段对比，必要时保存隔离快照以重放。

- **A 超大迁移**：构造多版本、重复段落、技术失败经验、人工约束和历史待办的大文档。运行 MIGRATE，检查原件可恢复、每个区段有映射、关键信息可达、入口显著缩小。报告实际大小与估算方法。
- **B 决策保护**：提供有出处的人工约束及与其冲突的 AI 建议/实现记录。检查要求原义保留、差异明确、未擅自替代。
- **C 过期状态**：旧文档写未上线、新文档声称已发布；提供只支持特定环境的证据。检查不按文字时间强判生产上线，能区分历史、当前事实与未核实声明。
- **D 重复更新**：相同输入连续 UPDATE 两次；比对第二次前后文档哈希和文件清单，验证无新增条目/快照和无意义重写。
- **E 追溯**：仅从新入口出发，定位关键历史决定、已验证规则、发布依据和原始映射；同时检查路径/标题及恢复哈希。
- **F 边界**：先 AUDIT 和 VALIDATE，比对全部文件哈希证明只读；迁移/更新前后比对源码、配置、数据和规则文件哈希。加入明确虚假的敏感值测试材料，检查不扩散且无安全恢复方案时暂停覆盖；不得接触真实凭据或生产服务。

记录实跑的动作、结果证据和未测项。结构验证器通过只能证明技能格式，不代表 A–F 行为通过。评估是否达到要求必须检查实际生成的文档及状态差异。

创建/维护本技能时，可按需查看 [已执行的验收记录](TEST_RESULTS.md)；它记录隔离测试，不作为业务项目事实。
